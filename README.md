## 📖 درباره پروژه

این پروژه یک **رابط کاربری (Frontend)** کامل برای یک فروشگاه آنلاین است که با **HTML، CSS و JavaScript خالص** ساخته شده. هدف این پروژه، نمایش توانایی در طراحی و پیاده‌سازی یک فروشگاه اینترنتی مدرن با تمرکز بر **تجربه کاربری (UX)** و **طراحی واکنش‌گرا (Responsive)** است.

**⚠️ توجه:** این پروژه فقط **فرانت‌اند** است و به **بک‌اند** متصل نیست. آماده‌ی اتصال به هر بک‌اند (Node.js، Django، Laravel و...) می‌باشد.

---

## ✨ ویژگی‌های کلیدی

- **طراحی واکنش‌گرا:** سازگار با موبایل، تبلت و دسکتاپ.
- **صفحه اصلی:** اسلایدر، دسته‌بندی‌ها، محصولات ویژه.
- **لیست محصولات:** فیلتر، مرتب‌سازی، جستجو.
- **صفحه جزئیات محصول:** گالری تصاویر، مشخصات، نظرات.
- **سبد خرید:** افزودن، حذف، تغییر تعداد.
- **صفحه پرداخت:** فرم اطلاعات، خلاصه سفارش.
- **پنل کاربری:** ورود، ثبت‌نام، تاریخچه سفارشات.
- **حالت تاریک/روشن:** سوییچ بین تم‌ها.
- **جستجوی زنده:** جستجو در محصولات.
- **ذخیره‌سازی محلی:** سبد خرید در `localStorage`.

## 🚀 نحوه‌ی اجرا

۱. **کلون کردن مخزن:**
```bash
git clone https://github.com/programmer-87/online-shop-ui.git
۲. ورود به پوشه پروژه:

bash
cd online-shop-ui
۳. اجرا:
فایل index.html را مستقیماً در مرورگر خود باز کنید. نیازی به سرور محلی یا ابزار build نیست.

یا با Live Server در VS Code اجرا کنید.

📋 صفحات و بخش‌ها
صفحه	شناسه	توضیح
صفحه اصلی	index.html	اسلایدر، دسته‌بندی‌ها، محصولات ویژه
محصولات	products.html	لیست کامل با فیلتر و مرتب‌سازی
جزئیات محصول	product.html	گالری، مشخصات، نظرات
سبد خرید	cart.html	مدیریت سبد
پرداخت	checkout.html	فرم اطلاعات و خلاصه سفارش
ورود	login.html	ورود / ثبت‌نام
🎯 قابلیت‌های فنی پیاده‌سازی‌شده
سبد خرید با localStorage: ذخیره‌سازی محصولات بدون نیاز به بک‌اند.

جستجوی زنده: فیلتر محصولات با تایپ.

فیلتر و مرتب‌سازی: بر اساس قیمت، دسته، محبوبیت.

حالت تاریک/روشن: سوییچ بین تم‌ها با ذخیره در localStorage.

انیمیشن‌ها: با CSS و IntersectionObserver.

اعتبارسنجی فرم‌ها: با JavaScript.

🔧 توسعه‌های آینده
□ اتصال به بک‌اند (Node.js + Express یا Django).
□ احراز هویت واقعی (JWT).
□ درگاه پرداخت آنلاین.
□ پنل مدیریت محصولات.
□ سیستم نظرات و امتیازدهی.
□ جستجوی پیشرفته با فیلترهای بیشتر.
□ PWA (اپلیکیشن وب پیشرونده).
